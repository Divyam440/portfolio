# Divyam Joshi — Portfolio

Personal portfolio of **Divyam Joshi**, Associate AI Software Developer building Generative AI and LLM-powered applications.

Built as a single page with plain **HTML, CSS and vanilla JavaScript**: no frameworks, no build step.

## Features

- Animated neural-network hero background, typing effect and scroll-reveal animations
- Light / dark theme with an animated switch
- **DJ.bot**: a scripted chat assistant that answers questions about my skills, projects and experience
- Command palette (`Ctrl/⌘ + K`) for quick navigation
- Project filters and case-study pop-ups
- Fully responsive, keyboard accessible, and respects `prefers-reduced-motion`
- Print-friendly layout (`Ctrl + P`)

## Run locally

Open `index.html` in a browser. That's it.
